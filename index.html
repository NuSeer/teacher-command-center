📖 How to Use the Teacher Command Center
🚀 Getting Started — First 3 Steps
1️⃣
Set Up Your Schedule

Go to ⚙️ Schedule Setup (sidebar → Settings). Add your periods, subject names, and times.

Example: Period 1 | Math | 8:15–9:05 | Class
Period 2 | Reading | 9:10–10:00 | Class

✅ Every dropdown, filter, and roster in the app updates automatically.

2️⃣
Add Your Students

Open Student Info. Four ways to add students:

  • Manual: Fill form → Save
  • CSV/Excel import: Export from PowerSchool or Infinite Campus → Upload
  • Drag & Drop: Drag roster file onto drop zone
  • Paste: Paste CSV text directly

✅ Student names auto-fill every dropdown in every tracker instantly.

3️⃣
Customize Your Features

Go to 🎛️ Customize Features (sidebar → Settings). Toggle off sections you don't use.

Example: Elementary teachers might turn off BOY Forms or Small Groups. Your data is never deleted — toggle back on anytime.

✅ Hub and sidebar update immediately.

🗺️ Hub Layout — What Each Row Does
👩‍🎓 Student Management

Student Info, Attendance, Seating Charts, IEP/504 (always on). Optional: Behavior Log, Missing Work, Participation, Small Groups, BOY Dashboard & Forms.

📊 Grades & Assessment

Gradebook — enter grades by period. Grade Dashboard — visual breakdown by letter grade. Progress Reports — students sorted lowest to highest.

💬 Communication

Parent Comm Log — every contact documented. Comm Dashboard — who hasn't been called yet. Conferences — meeting notes and follow-ups. Student Concerns — confidential referral tracking.

📅 Planning

Daily Planner — today's schedule with tasks, birthdays, events. Lesson Plans — filter by subject/period, linked to Curriculum Resources. Sub Plans + Sub Packet report. Task List.

🌟 Dashboards

Master Dashboard — full overview every morning. Academic Dashboard — grade trends by period. Comm Dashboard — parent contact gaps. Concern Dashboard — open referrals.

📁 Reports

12 printable reports: Student Summary, Class Report, Missing Work, Grade Report, Comm Report, At-Risk Students, Parent Meeting Packet, Sub Packet, Dismissal List, Discipline, Coaching/RTI, Period Patterns.

💡 Tip: Hub rows are drag-and-drop. Grab any row header and drag it to reorder. Double-click any row label to rename it.
🔗 How Features Link Together — Smart Connections

These features are connected — data entered in one place automatically shows up in others.

📁 Curriculum Resources → 📚 Lesson Plans

How it works: Add a curriculum resource (Google Slides, PDF, video, etc.) with a Unit name in Curriculum Resources. When you create a lesson plan and type that same Unit name, the resource appears automatically as a clickable card — click it to open instantly.

📋 Example:

  1. In Curriculum Resources: Add "Unit 3 Fractions Slides" → Unit: Unit 3 — Fractions → paste Google Slides URL
  2. In Lesson Plans: Create new lesson → type "Unit 3 — Fractions" in the Unit field
  3. A blue panel appears below with your slide deck — click to open

💡 Keep unit names consistent. "Unit 3" will also match "Unit 3 — Fractions".

👩‍🎓 Student Info → Every Tracker & Report

How it works: Once you add a student, their name appears in every dropdown across the entire app — Missing Work, Behavior, Parent Comm, Conferences, IEP, Small Groups, Participation, Seating Charts, and all reports. No re-typing names anywhere.

📋 Example:

Add Jordan Smith to Period 3 → Jordan instantly appears in:
• Attendance P3 roster
• Missing Work P3 dropdown
• Behavior Log dropdown
• Parent Comm Log dropdown
• Seating Chart P3 tray
• All reports filtered to P3

⚙️ Schedule Setup → Hub Folders + All Period Filters

How it works: Your schedule is the backbone of the app. The number of periods, their names, subjects, and times flow into: the header subtitle, roster folder cards, all period dropdowns, the Daily Planner, Lesson Plans subject filter, and the Sub Packet.

📋 Example:

Change from 7 periods to 4 → The header updates to "4 Periods", roster folders show P1-P4 only, all dropdowns show only P1-P4, planner shows 4 class slots, lesson filter shows 4 options.

💡 Add a subject to each period for multi-subject teachers — lesson filter shows "Period 1 — Math" instead of just "Period 1".

⚠️ Missing Work → Master Dashboard + Seating Chart + Reports

How it works: When you log a missing assignment, it immediately updates the Master Dashboard missing work count, turns the student's seating chart desk amber, adds a warning badge on the student roster card, and feeds the At-Risk report.

📋 Example:

Log "Unit 3 Test" as missing for Marcus → Master Dashboard shows 1 more missing, Marcus's desk turns amber in seating chart, Marcus appears in the At-Risk report (Missing Work flag), Parent Meeting Packet shows the missing assignment.

🎯 Behavior Log → Behavior Dashboard + Student Snapshot + Reports

How it works: Each behavior entry (with Level 1/2/3, action taken, and status) feeds the Behavior Dashboard bar chart, completion tracker, and student snapshot. The Student Snapshot panel lets you pull up any student's full behavior history, contact log, and trend line instantly.

📋 Example:

Log "Cell Phone" (Level 2, Detention, Pending) for Zoe → Dashboard bar chart updates, "1 Pending" stat updates, select Zoe in Student Snapshot → see all her incidents, last contact date, and recent next steps in one panel.

📞 Parent Comm Log → Comm Dashboard + Parent Meeting Packet + Reports

How it works: Every contact you log appears in the Comm Dashboard (shows who hasn't been contacted), feeds the Parent Meeting Packet (shows full contact history at the top of the report), and populates the Communication Report which is sortable by date, student, method, or reason.

📋 Example:

Log a Call Home for Marcus on 10/3 → Comm Dashboard removes Marcus from "Not Yet Contacted" list, Parent Meeting Packet for Marcus shows the 10/3 call in the contact history table, Comm Report includes it (sortable).

📋 IEP / 504 Records → Seating Chart + Rosters + Reports

How it works: Active IEP/504 records appear as purple desk borders in the seating chart, show a badge on period roster cards, populate the IEP Quick Reference Sheet (printable), and feed the Coaching/RTI report.

📋 Example:

Add an IEP for Destiny (Extended time, Separate setting) → Destiny's seating desk turns purple, Period 3 roster shows "IEP" badge next to her name, Coaching/RTI report lists her accommodations in the IEP column, Parent Meeting Packet references her active plan.

📅 Attendance → Stats + Dismissal List

How it works: Mark attendance daily (Present, Absent, Tardy, Excused, Late). The tracker shows a running attendance percentage per student. The dismissal field on each student drives the Dismissal List — bus numbers show automatically for Bus Rider students.

📋 Example:

Set Carlos as "Bus Rider, Bus #42" in Student Info → Dismissal List groups Carlos under Bus Rider, shows "🚌 Bus #42" on his card, prints Bus Rider section with bus number in the Dismissal List report.

👥 Small Groups → Master Dashboard Stats

How it works: Active small groups are counted on the Master Dashboard ("Active Groups" stat card). Log sessions directly on each group card. Groups show on the Coaching/RTI report with session counts. Students in groups are visible on the Dismissal List and roster cards.

📋 Example:

Create "Slope Intervention" group (Intervention, P3, Mon/Wed) with 3 students → Master Dashboard shows "1 Active Group", log 3 sessions → Dashboard shows 3 sessions logged total.

☀️ Daily Workflow
☀️
Morning (5 min): Open Daily Planner → check today's schedule and lessons. Check Master Dashboard for missing work count, grade average, and any open concerns. Attendance before first bell.
📚
During class: Log participation (positive and concerns). Note missing work immediately after collecting. Mark attendance before 8:15am deadline. Behavior logs go in right after the incident.
📞
After school: Log parent contacts while they're fresh. Update behavior status (Completed/Pending/Paused). Note any concerns or referrals. Update lesson plan status (Taught / Modified / Carried over).
📊
Weekly (Fridays): Check Academic Dashboard for grade trends. Run At-Risk Report — identify students needing support. Check Comm Dashboard for students not yet contacted this month.
🏫
Before an absence: Open Sub Plans → fill in each period's plan → generate Sub Packet from Reports. The packet pulls your current roster, IEP notes, lesson plan, and emergency contacts automatically.
🤝
Before a parent meeting: Open Reports → Parent Meeting Packet → select the student → print. The packet includes their current grade, missing assignments, behavior incidents, IEP status, and full contact history — nothing to compile manually.
🖨️ Printing All 12 Reports

All reports open in a new browser window. Click Print / Save as PDF, then choose your printer or select "Save as PDF" in the print dialog.

📄 Student Summary
One student, full profile — select student first. Good for parent meetings or admin requests.
📊 Class Report
All students or one period. Shows grade, missing work, contacts, concerns, medical flags. Use Landscape orientation.
❌ Missing Work Report
All outstanding missing assignments. Filter by period. Share with admin or use for parent calls.
📈 Grade Report
Grade distribution chart + full table sorted lowest to highest. Great for progress report prep.
💬 Comm Report
Sortable contact log. Click column headers to sort by date, student, method. Includes notes.
🚨 At-Risk Students
Check boxes for: Failing grade, 2+ missing, behavior incidents, open concern. Any combo triggers the flag.
🤝 Parent Meeting Packet
Select student → generates full meeting document with signature line, action items, and contact history.
📄 Sub Packet
Pick a date → pulls lesson plans, roster with medical/IEP flags, schedule, and sub instructions.
🚌 Dismissal List
All students grouped by dismissal type (Bus, Walker, Pick Up). Bus riders show their bus number.
🎯 Discipline Report
All behavior incidents sorted by date. Level, action, and status included. Good for admin documentation.
📊 Period Patterns
Compares periods by avg grade, missing work, and behavior — identifies which class needs most support.
📋 Coaching / RTI
Full class grid with grade, missing, behavior, IEP, and concern columns. Blank notes column for meetings.
💡 Tip: For wide reports (Class Report, Coaching), use Landscape orientation in your print dialog for best results.
🎛️ Customizing for Your Classroom
Elementary (self-contained): Set 4-6 periods with subject names (Math, Reading, Science, Social Studies, Writing, Specials). Turn off BOY Dashboard, Small Groups if not used. Dismissal List is essential.
Middle / High (departmental): Set 6-8 periods. All subjects the same. Use Period Patterns report to compare class performance. Behavior dashboard most useful here.
2 periods only? Delete extras in Schedule Setup. The app works with 1 period or 10. Everything adapts.
Your data stays private. Everything lives in your browser. Use Export in Schedule Setup to back up weekly. Clearing your browser cache will delete data — export first!
💡 Power Tips & Shortcuts
🔗 Unit name consistency — use the exact same unit name in Curriculum Resources and Lesson Plans for auto-linking to work best.
🪑 Seating chart colors — green = assigned, amber = missing work, pink = medical alert, purple = IEP/504. Glanceable at a substitute's eye level.
📊 Comm Report columns — click any column header (Date, Student, Method, Reason) to sort ascending/descending.
🎯 Behavior snapshot — select a student in the Behavior Dashboard's Student Snapshot panel to see their entire behavior history, last contact, and trend in one view.
🚌 Bus number field — appears automatically when "Bus Rider" is selected as dismissal type. Shows on the Dismissal List and print report.
📅 Planner birthdays — add dates of birth in Student Info to see upcoming birthdays in the Daily Planner sidebar.
🖨️ Parent Meeting Packet — generates automatically from your existing data. No prep needed — just select the student and print.
💾 Backup weekly — Setup → ⬇️ Export / Backup to Computer → saves a .json file to your Downloads folder. To restore: Setup → ⬆️ Restore from Backup File → navigate to Downloads → select the TCC_Backup file → click Open.
🔄 New Year Reset — go to Schedule Setup → 🔄 New Year Reset. Auto-exports your data, then clears students, grades, behavior, and attendance while keeping your schedule, lessons, and curriculum resources.
📋 Sample data — the app starts with demo students so you can explore every feature. When ready, go to Schedule Setup → 🗑️ Clear all data to start fresh. Your schedule setup is preserved.
⭐ Concern Referral — select a student in Concern & Referral, fill in your observations, urgency, and request, then print. Generates a full packet for the counselor including all your existing data + a counselor response section.
💬 Student Comm Report tabs — Parent Contact Log, Discipline Documentation, Coaching/Academic, and Admin Referral Packet each print a different version of the student's record. Coaching tab saves your intervention notes even after closing.

💾 How Backup Works
⬇️ Export / Backup to Computer
Saves a .json file to your computer's Downloads folder. Name: TCC_Backup_YourName_Date.json
✅ Do this weekly — or before clearing browser history.
⬆️ Restore from Backup File
Opens a file picker. Navigate to your Downloads folder (or wherever you saved the backup), select the TCC_Backup_...json file, and click Open.
✅ Use this on a new computer, new browser, or after data loss.
🔄 New Year Reset
Auto-exports your data to Downloads first, then clears students, grades, behavior, missing work, and attendance — keeping your schedule, lessons, and curriculum for next year.
